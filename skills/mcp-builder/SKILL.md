# MCP Server Builder Skill

## Summary

Four-phase engineering guide for designing workflow-oriented MCP tools, enforcing Pydantic v2 schemas (`extra="forbid"`), supporting summary/pagination parameters, and keeping `stdio` transport clean by logging strictly to `stderr`.
